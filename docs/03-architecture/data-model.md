# Data Model (PostgreSQL 18)

> Status: Baseline v1.0 (design). Migrations are written **per milestone** in `backend/src/main/resources/db/migration`
> (`V<yyyyMMddHHmm>__<module>_<change>.sql`, forward-only, ADR-0003). This document is updated in the same PR as the migration.

## 1. Conventions

| Topic | Rule |
|---|---|
| Schema | Single schema `app`. Table ownership per module is listed below (module-boundaries.md) |
| Names | `snake_case`, singular table names, FK columns `<target>_id`, index `ix_<table>__<cols>`, unique `ux_…`, check `ck_…` |
| PK | `id uuid PRIMARY KEY`, UUIDv7 generated by the application |
| Standard columns (aggregate roots) | `created_at timestamptz NOT NULL`, `updated_at timestamptz NOT NULL`, `created_by uuid NULL`, `updated_by uuid NULL` (user IDs, via JPA auditing), `version bigint NOT NULL DEFAULT 0` (optimistic locking) |
| Enums | `text` + `CHECK (col IN (...))`. No PostgreSQL enum types, because they are harder to evolve |
| Flexible data | `jsonb` only where the structure is type-specific or user-defined (question content, snapshots, custom fields, settings). Every jsonb column has a documented schema and is validated in code |
| Text search | `search_vector tsvector GENERATED ALWAYS AS (...) STORED` using the `app.simple_unaccent` text search config + GIN index; `pg_trgm` GIN on titles for fuzzy/prefix matching |
| Tags | `tags text[] NOT NULL DEFAULT '{}'`, normalised (trimmed, deduplicated case-insensitively) in code; GIN index |
| Ordering | `position integer NOT NULL`, `UNIQUE (parent_id, position) DEFERRABLE INITIALLY DEFERRED` |
| Deletion | **Archive, not soft delete** (ADR-0011): `archived_at timestamptz NULL` on library content. Hard delete only when unreferenced (`ON DELETE RESTRICT`). Children within an aggregate use `ON DELETE CASCADE` |
| Cross-module FK | Allowed for integrity (DEC-024); queries do not join across modules (except the read-only views owned by progress and dashboard) |
| Extensions | `CREATE EXTENSION IF NOT EXISTS unaccent; CREATE EXTENSION IF NOT EXISTS pg_trgm;` in V1 (requires the owner role; documented in deployment.md) |

  id uuid PK, username text NOT NULL, username_normalized text NOT NULL UNIQUE,   -- lower(unaccent(trim))

  status text NOT NULL CHECK (status IN ('ACTIVE','DISABLED')),
  must_change_password boolean NOT NULL DEFAULT true, temp_password_expires_at timestamptz NULL,

## 3. Security-sensitive fields

| Field | Sensitivity | Handling |
|---|---|---|
| `user_account.password_hash` | Secret | Never serialised; excluded from `toString`; only the identity module reads it |
| Temporary password (not stored in plain text) | Secret | Shown once in the create or reset response, sent with `Cache-Control: no-store`, never logged |
| `student.email`, `phone`, `contact_handles`, `student_guardian.*` | Personal data (possibly of minors) | Tutor-only DTOs; excluded from logs; part of export and delete (OQ-07) |
| `student_learning_profile.*`, `teacher_note.body`, `plan_item.tutor_notes` | Tutor-private | Never mapped to student DTOs (NFR-SEC-02) |
| `question.content` / snapshot answer keys | Answer secrets until release | Redacted by the type handler for the student audience |
| `audit_event.ip`, `user_agent` | Personal data | 1-year retention job |
| Spring Session attributes | Session secrets | Server-side only; cookie holds an opaque ID |

## 4. Migration and seed policy

- `V1` (T-M1.2): extensions, the text-search config and the Spring Modulith event registry (if its starter doesn't create it). The Spring Session and `persistent_logins` tables arrive with T-M2.1 (DEC-036). Every other table arrives with its milestone.
- **No domain seed data** in migrations: no folders, no metrics, no tags. Dev/test fixtures live in `backend/src/test/resources/fixtures` and `scripts/seed-dev`.
- Applied migrations are never edited. Destructive changes use expand → migrate → contract across two releases.
- A snapshot schema change bumps `snapshot_schema_version`. Readers must support every version ever written (with an upcaster in `activities.internal.domain.snapshot`).
