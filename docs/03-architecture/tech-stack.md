## 2. Backend

| Concern | Choice | Why | Rejected alternatives |
|---|---|---|---|
| Language/runtime | **Java 25** (LTS) | PO directive; modern language features (records, pattern matching, virtual threads) | — |
| Framework | **Spring Boot 4.1.x** | PO directive; mature security, data and test ecosystem | — |
| Project generation | **Spring Boot CLI `spring init`** | PO directive; reproducible scaffold | Hand-written build |
| Build | **Maven Wrapper** | Deterministic, widely understood by agents, no global install needed (ADR-0002) | Gradle: faster incremental builds but more variance in build logic |
| Modularity | **Spring Modulith** | Verifies module boundaries in tests, JDBC event publication registry, generated module docs (ADR-0001) | Plain packages + ArchUnit only: weaker; multi-module Maven: premature |
| Web | Spring MVC (servlet) + virtual threads | Simple blocking model; virtual threads cover I/O concurrency | WebFlux: complexity with no need |
| Persistence | **Spring Data JPA (Hibernate)** + **Flyway** | JSON mapping, auditing, optimistic locking; SQL-first migrations (ADR-0003) | jOOQ, Spring Data JDBC (see ADR-0003) |
| Database | **PostgreSQL 18** | jsonb, full-text search, `unaccent`, `pg_trgm`, `uuidv7()`, `NULLS NOT DISTINCT`; one engine covers search too | SQL Server (licence, ops); Elasticsearch (SPEC §36) |
| Auth | **Spring Security** + **Spring Session JDBC** | Server sessions survive restarts and are revocable per user (ADR-0005) | JWT (revocation, XSS token theft); Redis sessions (extra infrastructure) |
| API docs/contract | **springdoc-openapi** (Boot 4-compatible line) | Generates the OpenAPI document for client generation and the drift check (ADR-0014) | Hand-written spec (drifts) |
| Validation | Jakarta Bean Validation (Hibernate Validator) | Standard | — |
| HTML sanitising | **OWASP Java HTML Sanitizer** | Allow-list sanitising of rich text (NFR-SEC-09) | jsoup Safelist (acceptable fallback) |
| File type detection | **Apache Tika core** (detector only) | Do not trust client MIME types (NFR-SEC-10) | Extension checks alone |
| JSON | Jackson (version per the Boot 4 BOM) | Default; **note:** Boot 4 uses Jackson 3 (`tools.jackson.*` packages) | — |
| Observability | Actuator + Boot structured logging (JSON) | Enough for a single host | Prometheus/Grafana (later, if needed) |
| Scheduling | Spring `@Scheduled` | 3 small jobs; single instance | Quartz, ShedLock (only if there are ever > 1 instances) |
| Testing | JUnit (Boot BOM), AssertJ, Mockito, **Testcontainers** (PostgreSQL), Spring Modulith test, **ArchUnit**, JaCoCo, **PIT** (grading module) | See test-strategy.md | H2 (behaves differently from PostgreSQL) |

## 3. Frontend

| Concern | Choice | Why | Rejected |
|---|---|---|---|
| Framework | **React** + **TypeScript** (strict) | SPEC §36 suggests React; very large ecosystem | Next.js: SSR/SEO not needed for a private app and adds a Node runtime (ADR-0004) |
| Build | **Vite** | Fast; static output served by the backend | CRA (dead), webpack (slower config) |
| Package manager | **pnpm** (via corepack) | Strict node_modules (no phantom dependencies), fast, lockfile | npm (acceptable fallback) |
| Routing | **React Router** (data/library mode, lazy routes) | Mature, widely known | TanStack Router (typed search params; less familiar to agents) |
| Server state | **TanStack Query** | Caching, retries and mutation state; fewer hand-rolled loading bugs | Redux (unnecessary) |
| API client | **openapi-typescript** + **openapi-fetch** | Types generated from the contract; tiny runtime | Orval/axios codegen (heavier) |
| Forms | **React Hook Form** + **Zod** | Performant forms; schema validation shared with the UI | Formik |
| UI primitives | **React Aria Components** | Best-in-class accessibility, including date pickers, combobox, **keyboard drag and drop**, table, dialogs and i18n (vi) (ADR-0013) | Radix/shadcn (DnD and date pickers not included; tends to produce a "generic" look) |
| Styling | **CSS Modules + design tokens** (CSS custom properties) + **stylelint** (token enforcement) | Zero runtime; components own their styles; tokens enforce consistency (ADR-0013) | Tailwind (utility sprawl makes consistency hard to review); CSS-in-JS (runtime cost) |
| Icons | **lucide-react** | Consistent stroke icons; tree-shakable | Mixed icon sets |
| Font | **Be Vietnam Pro** (self-hosted via Fontsource) | Designed for Vietnamese diacritics; no third-party requests | Google Fonts CDN (privacy) |
| i18n | **i18next** + **react-i18next** (vi, en) | Common, supports namespaces and lazy loading | FormatJS (heavier API) |
| Dates | **@internationalized/date** (bundled with React Aria) + `Intl` | One date library, time-zone aware | Moment (dead), a second date library |
| Rich text editor | **TipTap** (ProseMirror): **proposed**, confirmed by an M4 spike | Extensible, outputs HTML that is sanitised on the server | Lexical, Quill |
| Sanitise on render | **DOMPurify** | Defence in depth (NFR-SEC-09) | — |
| Charts | In-house SVG `Sparkline` and `ScoreLine` (≤ 150 LOC) | Only 2 tiny chart types are needed (SPEC §27: few charts) | Recharts or ECharts (heavy for 2 charts) |
| Unit/component tests | **Vitest** + Testing Library + **MSW** + **axe-core** (direct, `web/src/test/axe.ts`) | Vite-native | Jest |
| E2E | **Playwright** (+ `@axe-core/playwright`), projects per viewport and engine | Multi-browser (incl. WebKit), visual snapshots | Cypress (no WebKit) |
| Lint/format | **oxlint** (the Vite 9 template default; react, react-hooks, jsx-a11y, import rules; DEC-042), Prettier, stylelint (token rules), `tsc -b` | Standard gates | — |

## 4. Delivery and operations

| Concern | Choice | Why |
|---|---|---|
| Containers | **Podman** (rootless) + Containerfile (multi-stage: web build → backend build → JRE runtime) | PO directive; daemonless, rootless |
| Local stack | `podman compose -f deploy/compose.dev.yaml` (PostgreSQL only; the app runs from the IDE or CLI) | Fast feedback |
| Production | **Quadlet** systemd units (app, db, caddy) on one host (ADR-0012) | systemd restarts, logs and auto-update; no orchestrator |
| TLS / proxy | **Caddy** | Automatic HTTPS with minimal configuration |
| CI | **GitHub Actions** | gh is available; free for this scale |
| Security scanning | gitleaks CLI (secrets; MIT, checksum-pinned, not the EULA-licensed action), Dependabot (dependencies), Trivy (image, release gate), `pnpm audit` | NFR-SEC-12/13 |
| Backups | `pg_dump` + file-volume archive, encrypted off-site copy. The tool (restic vs. plain `age` + rsync) is decided in M8 (OQ-03) | NFR-OPS-02 |

## 5. Explicitly NOT used (without a new ADR backed by evidence)

Microservices, Kafka, RabbitMQ, Redis, Elasticsearch/OpenSearch, Kubernetes, service mesh, GraphQL, event sourcing, CQRS
infrastructure, Next.js/SSR, MinIO (licensing and distribution changes; plain local volume first), any AI SDK, any payment SDK,
any analytics or tracking script.

## 6. Version policy

- Pin exact versions: the Maven BOM via the Boot parent; `pnpm-lock.yaml`; container images by tag **and** digest in production units.
- Use the Boot-managed version of every dependency the BOM covers. Pin non-BOM libraries explicitly and list them in §7.
- Upgrades: monthly Dependabot batch PR (`chore/<task-id>-deps-YYYY-MM`; the batch gets a backlog task ID, as merge-gate requires `<kind>/<task-id>-<slug>`) with the full gate. Major upgrades need a packet.
- **Boot 4 / Java 25 pitfalls for agents** are listed in `docs/09-harness/coding-agent-rules.md` §9.
