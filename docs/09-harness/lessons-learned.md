# Lessons learned (M0 → M2, 2026-09-25 → 2026-10-20)

Written by the LC at the PO's request before M2's remaining packets and M3 (DEC-139). Sources: the decision log (DEC-001..138), the M1
retro (`evidence/M1/retro.md`), the T-M2.18 measurement (packet `docs/tasks/T-M2.18-*.md`), the handoff gotchas, and the `shortcut:` ledger.
Each lesson: what happened (evidence), the root cause, and the rule now, with **where it is enforced**. An automated check beats a packet
rule, which beats a checklist, which beats a reviewer. **Read this file before writing a packet** (task-packet skill step 0).

## Working habits (LC)
- Use the project skills as procedures, not as background reading: `task-packet` for every packet, `evidence-and-handoff` at every merge and
  session end. The `ponytail` plugin (installed by the PO): its smallest-complete-change rule fits the scope rule; `/ponytail-debt` feeds the
  ledger review above. Its other modes stay optional: the gates and reviewers are the quality bar.
- Rule before G3, not after: an open question found at G1 is settled before the reviewer starts (L-10).
- Prefer fixing the cause in a shared place (a helper, a template block, a script check) over a reminder in the handoff.
